# AI-Enhanced Developer Portfolio

This is a personal project portfolio website developed using the MERN stack (MongoDB, Express.js, React, Node.js), enhanced with AI features for smart project filtering, skill suggestions, and chatbot assistance.

# Project Description

This portfolio showcases my technical skills, project experience, and learning journey as a Computer Science student specializing in Artificial Intelligence and Machine Learning (AIML). The portfolio includes:

- 📁 Dynamic display of projects with descriptions and GitHub links
- 🧠 AI-based recommendation engine to suggest skills and projects based on user interests
- 💬 Optional chatbot using GPT integration for interactive Q&A
- 🌐 Built with MERN stack for robust frontend and backend support

# Features

- Responsive, clean React UI
- Express + Node.js backend
- MongoDB for project data storage
- AI integration (optional) using OpenAI API or custom ML model
- Dark/light mode toggle
- Resume download and contact form

# Technologies Used

- Frontend: React, Tailwind CSS / Bootstrap
- Backend: Node.js, Express.js
- Database: MongoDB (Mongoose)
- AI/ML (optional): OpenAI API or Python ML model
- Hosting: GitHub Pages / Vercel / Render / Netlify
